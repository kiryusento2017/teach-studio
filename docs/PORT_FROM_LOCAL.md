# 跟本地版的逐项对照

云端版是从本地版 `pdf_to_word` 移植来的。这份文档记录**搬了什么、没搬什么、
为什么**，以及本地版还有哪些东西值得搬过来。

给将来接手的人：想加功能之前先翻这里，本地版很可能已经写过一遍，而且带着
实测踩坑的注释。

---

## 一、原样搬过来的（一行没改）

| 文件 | 行数 | 说明 |
|---|---|---|
| `pipeline/todocx.py` | 824 | 出 Word 的全部：公式占位符定位、表格边框、图片按英寸还原、主题字体、图内文字过滤。**逐字节相同** |
| `pipeline/probe.py` | 117 | PDF 体检。**逐字节相同** |
| `pipeline/tex2mml.js` | — | KaTeX 调用 |
| `pipeline/vendor/katex/` | — | KaTeX 本体。忘搬就是「一个公式都没转成」 |
| `app/renderer/index.html` | 178 | 样式表。**除了标题一个字没动** |

## 二、搬了但改过的

| 文件 | 本地版 | 云端版 | 改了什么 |
|---|---|---|---|
| `pipeline/tomath.py` | 231 | 256 | 加 `bundled_xsl()`，自带的 XSL 优先于注册表 |
| `pipeline/convert.py` | 164 | 164 | 砍掉进度回调、两轮识别；加多 token 换号 |
| `pipeline/paths.py` | 340 | 79 | 只留 `ROOT/TMP/LOGS/RUNTIME/ensure/find_exe/utf8_env` |

| `pipeline/sources.py` | 202 | 117 | 只留并发测速那一半，砍掉模型源和断点续传下载 |
| `server/main.py` | 1730 | ~460 | 砍掉显卡/模型/依赖/维护那一大片接口 |
| `app/renderer/pages.js` | 1821 | ~460 | 砍掉本地版特有的屏 |

## 三、没搬，也不该搬

这些是本地版的门槛，云端版存在的意义就是绕开它们：

| 模块 | 行数 | 干什么 |
|---|---|---|
| `pipeline/extract.py` | 496 | 起 MinerU 子进程本地识别 → 换成 `mineru_api.py` |
| `pipeline/gpu.py` | — | 显卡检测 |
| `pipeline/models.py` | — | 下 4.6 GB 模型 |
| `pipeline/torchdep.py` | — | torch 依赖 |
| `pipeline/vcredist.py` | — | VC 运行库 |
| `pipeline/deps.py` | — | 查 torch/mineru/模型的版本和上游 |
| `pipeline/upgrade.py` | 898 | pip 升级 torch/mineru，带备份回滚 |
| `tools/setup_env.py` | 110 | 装 MinerU 本体和模型 |

对应的接口也一并没搬：`/api/gpulib/*`、`/api/models/*`、`/api/vcredist/*`、
`/api/deps/*`、`/api/upgrade/*`、`/api/sources`。

## 四、🔴 该搬还没搬的

按该做的顺序排。

### 1. `LICENSE` —— 现在压根没有

本地版有，云端版没有。公开仓库没有许可证，别人法律上不能用。**最先补。**

### 2. `tools/build_release.py`（773 行）—— 没有打包脚本，发不了行

云端版 `tools/` 是空目录。没有它就：

- 出不了发行版（现在只能在开发环境跑）
- `version.json` 没人写 → 检查更新永远显示「当前版本 (未知)」
- `requires.json` 没人生成 → 更新时的依赖检查形同虚设

搬的时候要改：本地版分「完整包 0.69 GB / 更新包 0.4 MB」，云端版没有 torch
和模型，完整包小得多；打包**必须带上 `runtime/` 整个目录**（漏了 `pandoc.exe`
一份都转不出来，漏了 `xsl/MML2OMML.XSL` 公式全不是原生的）。

### 3. `tools/check_package.py`（233 行）—— 防止凭据混进安装包

检查打好的包里有没有不该有的东西。云端版**更需要这个**：`logs/token.json`
里是用户的 API token，一旦被打进包分发出去就是凭据泄露。

### 4. `/api/diag` + `/api/diag/export` + 前端 `diagText` —— 诊断导出

用户报「转不出来」时，让他一键导出诊断信息（环境、版本、最近的错误），
比来回问十遍快。本地版有整套，云端版没有。

### 5. `tools/check_docs.py` + `check_claims.py`（253 + 244 行）

一个查文档内部一致性，一个查「文档里说软件会怎么做」跟代码是不是对得上。
两个都是通用的，跟本地版/云端版无关。

### 6. `tools/check_release.py`（354 行）—— 发布后自检

Release 传上去之后立刻验一遍：资产在不在、大小对不对、SHA256 对不对。

### 7. 前端的进度条组件 `bar` / `barPct`

云端版更新下载现在只显示一个百分比数字。本地版有画好的进度条，样式表
（`index.html`）本来就是同一份，搬过来直接能用。

### 8. `/api/update/probe` + 手动选线路

本地版允许用户点「测下载速度」，然后手动指定用哪条镜像。云端版后端
`update.download` 的 `prefer` 参数留着，但没有接口和界面暴露它。

### 9. `/api/ping` —— 健康检查

一行的事，排查「前端连不上后端」时有用。

### 10. `paths.free_bytes` / `enough_space` —— 磁盘空间检查

转换前、下更新包前检查空间够不够。云端版没有，磁盘满时的报错会很难看懂。

### 11. `maint.py` 的**日志清理**部分

本地版整个 `maint.py`（781 行）大半是清 pip 缓存和 torch 临时目录，云端版
用不上。但 `scan_logs()` 那部分适用 —— `logs/` 下的 `runs.json` 上限 200 条、
`usage.json` 留 7 天，都有上限，问题不大，属于低优先级。

### 12. `启动.cmd`

本地版根目录有，双击即可。云端版没有。

## 五、云端版**修好了**本地版的哪些毛病

这些是移植时特意做了不同选择的地方（本地版 2026-09-08 三个 agent 全量审查
查出三十余条，作者定「全部不管」，所以那边还留着）：

| 本地版的问题 | 云端版怎么做的 |
|---|---|
| `HTTP.get` 不检查 `r.ok`，404 当成正常数据 resolve，为它写的 catch 是死代码 | `httpGet` 第一版就检查状态码，有测试钉着 |
| 任务表淘汰会把 running 的挤掉，互斥失效 | 只淘汰终态，有测试 |
| 轮询返回浅拷贝，序列化在锁外，日志被工作线程截断 | 在锁内就拷好，有测试 |
| 同一条忙碌判据抄了四处，一处漏了新增项 | 只有 `_busy()` 一个函数 |
| 五处「功能写好了、接口通了、前端没人调」 | 契约测试扫后端每条路由有没有前端调用点 |
| 报告页返回按钮在内容后面，被 `min-height:100%` 挤出屏幕 | 按钮在前，测试断言「按钮位置 < 内容位置」 |
| 查更新的线路表在网络慢时显示「未测」（单条超时 > 收集窗口） | 搬过来时那两个数的关系已经是对的，并加了测试钉住 |

## 六、云端版**多出来**的（本地版没有）

| | 说明 |
|---|---|
| 不用装 Office | `MML2OMML.XSL` 随包内置。本地版要求用户机器上有 Office |
| 多 token 叠加额度 | 1~10 个栏，按本地账挑号，撞额度自动换 |
| 双队列 | 转换进行中还能继续加文件排队。本地版正转着就不让加 |
| 轮询数据没变就不重绘 | 治本地版「上下滑动会顿一下」那个 bug。**本地版用不了这一招** —— 它每秒回来的 `elapsed`/`remain` 必然在变，判不出相等 |

## 七、测试规模对照

| | 本地版 | 云端版 |
|---|---|---|
| 测试文件 | 23 个 | 2 个 |
| 后端用例 | 分散在 18 个 `test_*.py` | 98 条（单文件） |
| 前端 | `front_check.js` | `front_check.js`，49 条 |
| 真实转换验证 | `real_convert_check.py` 等 4 个 | **没有** |

本地版那 4 个 `real_*.py` 是真跑一份 PDF 出 Word 的端到端验证（不 mock）。
云端版没有对应的东西 —— 每跑一次要烧云端额度，得想清楚怎么做才不浪费。

# 台账

决定过的事记在这儿，连同**为什么**。免得后人（包括几个月后的自己）
再把同一条推一遍，或者把一个有理由的选择当成疏忽给"修"掉。

## 一、悬而未决

| # | 事项 | 现状 | 怎么了结 |
|---|---|---|---|
| 1 | **单次页数上限** | 代码 `MAX_PAGES=600`，官方文档写 200 | 传一份 300 页的试试，看服务端收不收 |
| 2 | **记账时机** | 上传成功那一刻就记 | 传一份立刻点停止，等几分钟看后台用量涨没涨 |
| 3 | **WPS 能不能双击编辑公式** | 没验过 | 用 WPS 打开任一产物，双击公式看光标进不进得去 |
| 4 | **macOS 能不能"卸载干净"** | Electron 四个路径都重定向了，但 Cocoa 的 `Saved Application State` 和 `Preferences.plist` 管不着 | 打包后真机跑一次，看 `~/Library` 下留了什么 |
| 5 | **打包脚本** | 没有，`tools/` 是空的 | 照搬本地版 `build_release.py`（773 行） |
| 6 | **安卓 / iOS** | 打不了 | 见下面「已经定了的」第 9 条 |

## 二、已经定了的

| 事项 | 决定 | 理由 |
|---|---|---|
| 1. `MML2OMML.XSL` | **内置进发行包** | 只发给几个熟人，他们没装 Office，也不想为转个讲义装一套。这是微软的版权文件，仅限小范围私下使用 |
| 2. 仓库可见性 | **public，XSL 也放进去** | 作者要方便做测试。风险已知（公开分发微软版权文件），是他的决定 |
| 3. 「直接打开网页」 | **整条链路删掉** | 弹不弹得出浏览器取决于用户机器的默认程序关联、协议注册、安全软件——保证不了。替代品是「复制地址」 |
| 4. 额度用法 | **只用来挑号，从不拦人** | 页数（1000/天）是**软**上限，超了只是排队降优先级；而且本地账只算得到本软件用掉的，天生偏小 |
| 5. 记的是页数不是文件数 | 页数 | 文件数上限 5000/天，正常传不完；页数一份讲义二三十页，五十份就到顶 |
| 6. 同内容的重复文件 | **照转不误，但复用识别结果** | 放两个目录多半就是想在两处各拿一份 docx。省的是额度，不是产物 |
| 7. `pick_order` 不做「够不够」筛选 | 只按剩余排序 | 剩得多的号必然先够，两种排法结果**永远相同**——加过那一层，发现是死代码，拆了 |
| 8. 不做转换进度条 | 只给「第几份 / 共几份」 | 云端只返回 `pending/running/done`，编一个百分比不如不给 |
| 9. **安卓 / iOS 不做** | 不做 | Electron 不支持移动端；pandoc 没有移动端二进制；iOS 的 App Store 政策不允许运行时执行下载的代码。更根本的是：产物是 .docx，用户要在电脑上用 Word/WPS 编辑公式——手机上转完然后呢？真要移动端，合理形态是网页版（服务器转换、手机浏览器上传下载），那是另一个项目 |

## 三、栽过的坑（同一个形状别再来第二次）

| 坑 | 形状 | 教训 |
|---|---|---|
| 「数据没变就不重绘」从没生效 | 后端每秒返回一个界面上**根本不显示**的 `elapsed`，签名每秒都变 | 签名要**反向排除**，不要正向列举；而且注释里写下的原则要回头核对实现 |
| 测试写死 `elapsed: 5` | 构造得不真实，bug 在测试全绿的情况下活了三天 | 测试夹具要照**真实数据**造 |
| 契约测试硬编码 `/cancel` | 新加 `/append` 时后端接口没人调，测试照样绿 | 检查不能建在「写法」上，要真解析 |
| 测试直接动 `logs/token.json` | 改了 `set_token` 语义之后，跑一次测试把用户两个 token 覆盖成一个 | 隔离要在**模块级**兜住，靠每个测试类自觉是靠不住的 |
| 云端识别质量比本地差三成 | `is_ocr` 默认 `false`，走了没有公式的文字层 | 参数默认值要逐个对着本地版核 |
| `start` 后没清待选清单 | 转换中列表下面又原样列一遍同一批文件 | 同一件事两个地方做（`start` / `appendQueue`），漏一个不报错 |
